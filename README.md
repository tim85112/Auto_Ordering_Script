# 外賣訂單工具

這是一個簡單易用的 GUI 工具，可以讓您自動執行外賣訂單腳本，包括 Foodpanda 和 UberEats。

## 功能特點

- 顯示所有店家及對應編號
- 自動執行工作流：先執行 UberEats 腳本獲取訂單 JSON，成功後自動執行 Foodpanda 腳本
- 支援多個店家同時執行
- 實時顯示腳本執行日誌
- 可隨時停止所有運行中的腳本

## 如何使用

1. 執行 `food_delivery_tool.py` 腳本啟動 GUI 工具

   ```
   python food_delivery_tool.py
   ```

2. 在應用程式主界面上，您將看到所有支援的店家及其編號

3. 在輸入框中輸入您想執行的店家編號，用逗號分隔
   例如：輸入 `1,5`（表示肯德基、八方雲集）

4. 點擊「開始執行」按鈕，或直接按 Enter 鍵

5. 工具將按照以下順序執行：

   - 先執行所選店家的 UberEats 腳本以獲取訂單數據
   - UberEats 腳本成功完成後，自動執行相應的 Foodpanda 腳本

6. 腳本執行情況將顯示在下方的日誌框中

7. 如需停止所有腳本，點擊「停止所有」按鈕

## 工作原理

- UberEats 腳本（如 ubereats_kfc.py）會從購物車中提取訂單數據，並保存為 JSON 檔案
- Foodpanda 腳本（如 foodpanda_kfc.py）會讀取該 JSON 檔案，並自動在 Foodpanda 網站下單
- 本工具確保按正確順序執行這些腳本，等待 UberEats 腳本完成後再執行 Foodpanda 腳本

## 系統要求

- Python 3.6+
- tkinter (通常隨 Python 安裝)
- 各店家對應的腳本文件必須存在於同一目錄

## 注意事項

- 本工具僅運行現有的店家腳本，不會修改腳本內容
- 執行腳本時，可能會彈出多個瀏覽器窗口
- 請確保您已安裝了腳本所需的所有依賴項
- 腳本執行期間請勿關閉瀏覽器窗口

## 故障排除

如果應用程式運行時出現問題：

1. 確保所有腳本文件都在正確的位置
2. 檢查 Python 及相關依賴是否正確安裝
3. 查看日誌窗口中的錯誤信息
4. 如果 UberEats 腳本失敗，相應的 Foodpanda 腳本將不會執行
5. 如果某個腳本持續失敗，可以嘗試單獨運行該腳本進行調試
